# Project Direction Plan R18

The new sanitized-text source-discovery specification is frozen. It requires
observed posts, messages or website copy in inert text formats and rejects
warning-only, registry-only, synthetic-only, HTML-only and unlicensed sources.

Next: prepare and independently verify one bounded discovery release capped at
12 search queries and 20 shortlisted sources. The release may inspect only
dataset landing pages, documentation, terms and paper metadata. It must not
download source files, visit candidate domains, retain raw HTML, label records
or run a model.
