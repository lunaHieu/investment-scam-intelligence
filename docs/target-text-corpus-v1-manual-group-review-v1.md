# Target Text Corpus V1 — bounded manual group review V1

This review asks only whether the 22 minimum-content artifacts should remain distinct technical groups or be linked because of affirmative cross-domain clone, shared-control, case/campaign, or entity-family evidence. It does not decide `CONFIRMED` or `LEGITIMATE` ground truth.

The frozen packet exposes exact source-reference identity, candidate entity and host, immutable text path/hash, declared canonical URLs, extracted contact indicators, and automated overlap/grouping results. Reviewers may flag identity or task-content anomalies for the later primary review, but such flags are not labels.

A merge requires named positive linkage evidence such as a shared distinctive contact identity, copied distinctive content, the same official case reference, or official evidence linking both domains. Generic financial vocabulary, a shared acquisition channel, warning/registry membership by itself, and model predictions are not linkage evidence. If the relationship cannot be resolved offline, it must remain unresolved rather than being forced into a group.

No network access, model operation, label creation, or validation/test opening is allowed in this review.
