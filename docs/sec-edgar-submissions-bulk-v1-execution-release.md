# SEC EDGAR submissions bulk V1 execution release

## Step name

Freeze the one-shot SEC bulk execution release.

## Meaning

The release converts the previously tested acquisition plan into one narrowly scoped network operation. It permits one request to the exact official SEC `submissions.zip` URL and binds the request to the frozen protocol, tooling registry, raw output path, and manifest path by SHA-256.

The private SEC identity file was checked for existence and required field structure. Its contents and hash are not published. The downloader must validate it again at runtime.

The release does not enumerate candidates, capture candidate websites, create labels, open validation or test, fit a model, score a model, activate DFPI, or activate Vietnamese issuer-reference collection. A successful raw archive and manifest consume the release.
