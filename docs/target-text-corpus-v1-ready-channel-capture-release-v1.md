# Ready-channel capture execution release V1

This release authorizes one later archive-only attempt for the exact 53-row
eligible capture plan after independent release QA. It is immediately eligible
after creation; no universal 24-hour delay is introduced. A separate
invocation remains mandatory so preparation and network execution cannot be
silently combined.

The executor uses raw Wayback replay only, at least 30 seconds per request, one
attempt per snapshot, crash-safe non-resumable partial reservation, no
overwrite and stop-on-first-error behavior. Independent result QA recomputes
membership and every captured byte/hash. No candidate live domain, label,
validation/test split, score or training operation is permitted.
