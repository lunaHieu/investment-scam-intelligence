# Real-World Source Missing-Evidence Checklists V1

ScamBench and Vietnamese SMS remain on hold. Each now has seven explicit,
blocking evidence requirements. The checklists accept publisher documentation,
terms, papers, manifests, checksums and written clarification; they do not accept
downloaded records or labels inferred by inspecting text.

ScamBench must resolve gated conditions, upstream provenance, privacy,
adjudication, grouping and file identity. Vietnamese SMS must provide a
publisher-defined investment subset, annotation evidence, provenance, grouping,
test sealing and file identity. If no investment subtype exists, Vietnamese SMS
may only be reconsidered later as a general auxiliary source with zero fresh
credit; keyword filtering cannot manufacture investment labels.

No author contact, dataset download, candidate-domain access, labeling or model
operation is authorized by these checklists.
