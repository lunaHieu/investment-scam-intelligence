# C1 — Parallel offline workstream V1

Date: 2026-10-23

## Meaning

C1 formally defines what the project may do while A1/A2 and B5 are waiting on
their archive time gates. C is not another network shortcut. It is the
governance and intake branch for sources that still require a lawful external
artifact, written reuse basis or truthful human decision.

## Current boundary

- Dataset V1-Core requires 300 independent groups; 0 are admitted.
- Forty-two owner-accepted SEC EDGAR records are conditional supply, leaving a
  conditional residual gap of 258 groups.
- CFTC RED still lacks a documented lawful capacity route for its 75-group
  channel.
- DFPI accepts only a user-supplied first-party artifact or explicit official
  export under the existing packet.
- SSC and HNX remain blocked until an explicit official export or written reuse
  basis is retained.
- A5 has 42 hash-verified language tasks, all pending truthful human review.

## Permitted work

C1 permits offline schema/verifier preparation, byte/hash validation for a
future supplied artifact, rights-evidence registration, source-role/capacity
audits and verification of a future exact-42 human language response.

It does not permit web search as a substitute for a missing artifact, live
candidate-domain access, candidate enumeration, archive capture, labels,
validation/test opening, scoring or training. It cannot mutate A1/A2, B2-B5 or
the existing owner-accepted decisions.

## Ordered continuation

1. C2 validates a genuinely supplied lawful artifact or rights record and
   creates a new versioned readiness ledger.
2. C3 verifies a truthful exact-42 language-review response and recomputes
   language supply without changing labels.
3. C4 may freeze a new matrix or enumeration release only after the relevant
   source-capacity, terms and rights gates pass; any network execution still
   requires its own release.
