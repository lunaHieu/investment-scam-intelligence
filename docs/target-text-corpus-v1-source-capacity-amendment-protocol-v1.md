# Dataset V1-Core source-capacity amendment protocol V1

This protocol separates one executable preparation path from two still-blocked source proposals.

## SEC EDGAR bulk universe

SEC documents `submissions.zip` as the nightly bulk archive for public Submissions API history across all filers. A one-shot acquisition plan may now be implemented for the exact official HTTPS URL. Execution remains closed until the downloader independently verifies the private User-Agent file at runtime without printing or publicly hashing it.

The run is limited to one bulk request, a project cap of one request per second, immediate stop on HTTP 429 or policy change, no overwrite, and immutable raw SHA-256 registration. The ZIP central directory must be checked for absolute or parent-traversal members before extraction. A larger universe does not permit weaker identity matching: the existing 0.8 name-match and 0.15 runner-up-margin thresholds remain fixed.

## DFPI tracker

DFPI is registered only as a candidate-seed source. Its tracker describes consumer complaints and explicitly notes that reported losses are not verified. No automated table or case-page scraping is authorized by this protocol. A future manually acquired or explicit official export must have its own versioned manifest, and every proposed `CONFIRMED` case still needs independent official corroboration and exact observed-artifact linkage.

## Vietnamese official issuer references

HNX/HOSE/SSC references remain blocked for collection. Official profiles can support issuer identity and official-domain reconciliation, but they cannot automatically prove that an artifact is legitimate or uncompromised. Before activation, the project needs a source-registry addendum, an explicit download or written reuse basis, no-redistribution rules, exact issuer/domain checks, and a separate Wayback artifact.

Adopting DFPI or a Vietnamese reference channel requires Sampling Matrix V2. Matrix V1 cannot be silently edited or have its quotas reassigned.

No network operation, official-data download, candidate enumeration, artifact capture, label creation, model operation, or partition opening occurs in this protocol-freeze step. The next permitted action is implementation and independent verification of the one-shot SEC bulk downloader and manifest builder.
