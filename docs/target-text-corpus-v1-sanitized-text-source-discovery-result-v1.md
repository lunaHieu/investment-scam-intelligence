# Sanitized Text Source Discovery Result V1

The bounded 12-query metadata search completed without downloading a dataset,
opening a candidate domain, retaining raw HTML, creating labels or operating a
model. Six of sixteen considered sources advance to independent second review.

The primary candidates are ScamBench, because it separates investment scam and
non-scam CSV files, and the Vietnamese SMS Dataset, because it contains 2,991
real consented and anonymized messages under CC BY 4.0. Sting9, PhishVN visible
text, NexVision and When the Fed Speaks are conditional candidates with narrower
roles or unresolved format/provenance constraints.

No source is approved for acquisition yet. The next gate is an independent
second review of the six-source shortlist against the frozen eligibility rules.
