# Target Text Corpus V1 Vietnamese channel terms V1

## Step name

Register and terms-review one Vietnamese official-reference path for each target status.

## Meaning

The multilingual supply audit found zero verified Vietnamese artifacts because the current pools contain reference metadata rather than reviewed visible text. This step defines how Vietnamese official sources may support future candidate discovery without turning their content into labels or model features.

## `CONFIRMED`: SSC investor warnings

The State Securities Commission of Vietnam investor-warning index is registered as an official case-seed and entity/domain evidence source. An SSC warning may support a future `CONFIRMED` decision only after exact case linkage, a separate archived candidate artifact, complete grouping, blind second review, reconciliation, and owner acceptance.

The reviewed official page exposes public warning titles, dates, and individual pages, but this review did not identify an explicit bulk export or machine-reuse license. Generic automated enumeration is therefore not authorized. Warning prose remains evidence only and cannot be model input.

## `LEGITIMATE`: HNX issuer profiles

Hanoi Stock Exchange issuer profiles are registered as identity, listing-status, and official-domain references. A listing is not a safety guarantee. A future `LEGITIMATE` decision still requires exact domain reconciliation, an archived investment-related artifact, clone/compromise/redirect/impersonation checks, complete grouping, blind second review, reconciliation, and owner acceptance.

The reviewed HNX pages state HNX copyright and instruct users to contact HNX when publishing information from the website. This protocol therefore authorizes neither generic scraping nor redistribution. Only a later manual/explicit official export or written reuse basis may open a hash-bound acquisition release.

## Gate result

Both source roles are now registered, but acquisition remains blocked. Sampling Matrix V1 is unchanged; adopting either Vietnamese path requires a separately frozen Sampling Matrix V2. Candidate enumeration, capture, labeling, validation/test access, and training remain prohibited.

The next gate requires a manual/explicit official export or written reuse basis for each activated path, followed by Sampling Matrix V2 and a hash-bound acquisition release.
