# Target Text Corpus V1 Metadata Evidence Release V1

This release freezes a bounded, public-metadata-only evidence pass for three
branches: NexVision, ScamBench and Vietnamese SMS. It contains 21 exact evidence
questions and six exact search queries. At most 18 pages may be read, with no
more than three followed document links per source.

The pass may inspect only primary publisher or repository documentation,
dataset cards, licences/access conditions, immutable commit or release metadata,
file-tree metadata, paper landing pages/abstracts, manifests and checksum pages.
It may not download or open dataset records, clone a repository, retain raw HTML,
contact authors, access candidate domains, execute code, create labels, open
validation/test data or perform any model operation.

Missing evidence remains missing. Search-result snippets and absence of a public
statement cannot be converted into a positive or negative fact. A separately
verified result is required before any acquisition decision can be reconsidered.
