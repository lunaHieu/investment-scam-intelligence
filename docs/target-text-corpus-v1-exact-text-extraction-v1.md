# Target Text Corpus V1 — exact-text extraction V1

## Scope

This gate converts only the 23 Wayback captures that passed the independent raw-byte audit into deterministic UTF-8 visible-text artifacts. It is an offline transformation, not evidence review and not labeling.

The frozen configuration pins the candidate queue, capture report, independent raw-capture QA, governing protocol, and capture-result registry by SHA-256. Before writing an output, the extractor validates every pinned input, the exact 23-row population and channel distribution, every raw capture byte count and SHA-256, and the previous gate decisions.

## Deterministic transformation

For each captured row, the extractor:

1. reads the immutable raw capture;
2. decodes gzip transport compression when present, without modifying raw bytes;
3. runs `extract_visible_text` using the repository's frozen HTML normalization behavior;
4. encodes the result directly as UTF-8, without adding a final newline;
5. writes one immutable `.txt` file named by candidate ID; and
6. records raw, decoded, and text byte counts and SHA-256 hashes in a JSONL manifest.

The protocol minimum is 20 non-whitespace characters. Text below that threshold is still preserved and explicitly routed as `BELOW_MINIMUM_PRESERVED`; it is not silently deleted, repaired, or replaced.

## Independent verification

The verifier starts again from the pinned raw captures, independently repeats decoding and visible-text extraction, and compares every generated text file byte-for-byte with the regenerated bytes. It also checks manifest equality, output file membership, report counts, the minimum-content gate, and the continued no-label/no-model restrictions.

Only a passing independent QA result can release the next offline stage: post-capture exclusion and transitive grouping. Human label review remains closed until that later stage passes.

## Safety boundary

- Network operations: 0.
- Live candidate-domain access: prohibited.
- Raw capture changes: 0.
- Ground-truth labels created or changed: 0.
- Model fitting or scoring: 0.
- Validation or test openings: 0.
- Training eligibility changes: 0.
