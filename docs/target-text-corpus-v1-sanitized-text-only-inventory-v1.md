# Sanitized Text-Only Inventory V1

The project currently has one substantial safe text artifact: Mendeley V2
(16,202 CSV rows). Only the frozen 3,916-row historical train split is presently
authorized for baseline work; it earns no fresh V1-Core credit. Validation and
test remain sealed.

IOSCO (47,001 rows) and Crimson (43,572 rows) are metadata/reference layers,
not text-training corpora. SEC/IAPD and every Wayback-derived visible-text
artifact are excluded because the raw-HTML branch was abandoned. No current
fresh V1-Core group or new training row is admitted.

The safest candidate order is DFPI text narratives, UBCKNN Vietnamese warning
text/PDF, then FCA/IOSCO evidence-linked narrative fields. Every candidate needs
a text-only acquisition method, provenance, license/terms review, sanitization,
deduplication, leakage control and independent evidence review before admission.
