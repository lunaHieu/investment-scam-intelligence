# Sanitized Text Source Discovery Specification V1

The project needs observed investment-related text, not another warning list.
This specification defines the acceptance boundary before any web search.

A source is eligible only when it offers inert UTF-8 text files, a retained
license or reuse basis, record-level provenance, stable identifiers and text
that is itself a post, message or website communication. Evidence for
`CONFIRMED` or `LEGITIMATE` must remain independent from that text.

The future search is capped at 12 queries and 20 shortlisted sources. It may
inspect search metadata, official dataset pages, documentation, terms and paper
abstracts. It may not download files, open candidate domains, retain raw HTML,
follow links embedded in datasets, create labels or run a model.

Every shortlist requires an independent second review, source-registration
addendum and separate acquisition release. This specification itself authorizes
no network operation.
