# Project Direction Plan R17

The sanitized text-only inventory, intake protocol and three-source assessment
are complete. DFPI, UBCKNN and FCA remain useful evidence channels but none is
a fresh observed-text channel: they contribute complaint or regulator evidence,
not the distinct post, message or website copy the model is intended to predict.

Next: prepare an offline source-discovery specification for lawful inert-text
datasets. It must require first-party or explicitly reusable TXT/CSV/JSON/JSONL,
record-level provenance, observed investment-related content, independent label
evidence and leakage-safe grouping. No web search or acquisition begins until a
separate bounded discovery release is frozen and independently verified.
