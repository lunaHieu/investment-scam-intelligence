# NexVision Synthetic Auxiliary Source Registration Addendum V1

NexVision is proposed as an AUX synthetic source only. It receives no fresh
V1-Core credit and cannot become Gold, independent validation, external
benchmark evidence or a substitute for real-world records.

The addendum does not activate the source or alter `registry/sources.json`.
Before activation, a metadata-only gate must pin an immutable commit/release,
exact inert data files, licence, dataset card, manifest and checksums. A future
acquisition may accept only inert text formats, cannot clone or execute the
repository, and must abandon the batch on any malware/PUA detection.
