# Target Text Corpus V1 Public Metadata Gap Resolution Release V1

This release covers only Lane A tasks A01-A04. It allows one new exact-title
metadata query, seven exact public first-party pages, at most eight non-PDF page
reads and at most 24 pages of the peer-reviewed ScamBench paper.

It may read official commit metadata, manifest/checksum text, research-paper
text and publisher documentation. It may not repeat exhausted pages or queries,
open dataset records, open CSV/JSONL data, download data, clone repositories,
accept gated conditions, contact publishers, retain raw HTML, create labels,
open validation/test data or run models. Malware or PUA detection abandons the
artifact or batch without restore or whitelist.
